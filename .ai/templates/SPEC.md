## 7. Stop Triggers

- If a path, interface, schema or step is missing or ambiguous: append `[SPEC-AMBIGUITY]` to
  `history/ISSUES.md` and stop.
- If the task requires a structural change outside this SPEC: stop and escalate to the architect.
- If a forbidden dependency or an unapproved network need appears: stop and require a decision.
- If `ui_scope` is `none` and the diff touches UI files: stop (`[SPEC-UI-DRIFT]`).
- If a visual detail, primitive, state or token is not in the contract: stop; never invent.
- If a translation is missing in either locale: stop; never ship a partial UI.
